# pi-waves

Calm mode for [Pi](https://pi.dev): while Pi works, a full-width wave animation replaces the
"Working..." row, and thinking, short mid-turn notes, and tool rows are hidden. The waves fade
out when Pi is done.

Install: `pi install git:github.com/matthewkope/pi-waves`
Toggle: `/waves`, `/waves on`, `/waves off` (saved in `~/.pi/agent/waves.json`)

Hiding behaviour ported from Firstmate's Calm (MIT): https://github.com/kunchenguid/firstmate
